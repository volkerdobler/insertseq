# What's New - Version 1.4.0

## Highlights (1.4.0)

- **Smart Trailing-Text Shift on Multi-Line Overflow**: When generating more sequence items than active cursors (for example with a stop condition like `1@i>9`) using newline separation (`delimiter === null`), any text following the cursor on the same line is now cleanly shifted to the end of the inserted sequence instead of remaining stuck on the first line:
    - Cursor at the start of a line before existing text (`|abc` with `1@i>2`) inserts the full sequence above and moves `abc` to a new line below (`1`, `2`, `3`, `abc`).
    - Cursor in the middle of a line (`foo|bar` with `1@i>2`) keeps the prefix `foo` on the first line and attaches the suffix `bar` to the last overflow line (`foo1`, `2`, `3bar`).
    - Explicit horizontal delimiters (such as space `1_ :1@i>2` or comma `1_,:1@i>2`) continue to insert inline at the cursor position and shift trailing text horizontally to the right (`foo1 2 3bar`).
- **Multi-Cursor Placement on All Inserted Overflow Lines**: When a sequence inserts additional overflow lines beyond the original cursor count, active cursors (`editor.selections`) are now automatically placed at the end of **all** newly inserted lines, enabling immediate multi-cursor editing across the entire generated block.
- **Packaging & Dependencies**: Updated dependencies and pinned `temporal-polyfill` to `1.0.4` for reliable packaging and CI builds.

See `CHANGELOG.md` and `README.md` for full details and examples.

## 🔭 Outlook: What's Coming in Version 2.0.0

Version `1.4.0` is the final planned minor release in the `1.x` series. Work on **Version 2.0.0** is already underway. Please review the upcoming architectural changes and removals so you can prepare your settings in advance (or pin `1.4.0` if you rely on legacy configurations):

### ⚠️ Breaking Changes & Removals in 2.0.0

- **Removal of Deprecated Setting `insertseq.insertOrder`**:
    - The legacy setting `insertseq.insertOrder` (`"cursor"`, `"sorted"`, `"reverse"`), which has been deprecated since `v1.1.1`, will be removed in `2.0.0`.
    - **Action required**: Please migrate your `settings.json` to the boolean settings `"insertseq.sortedOutput"` (`true`/`false`) and `"insertseq.reversedOutput"` (`true`/`false`).
- **Stricter, Deterministic Syntax Parsing (AST Engine)**:
    - The legacy regular-expression cascade is being replaced by a deterministic **Lexer / Tokenizer & Recursive-Descent AST Parser** (`docs/GRAMMAR.md`).
    - While 100% of documented syntax remains supported, ambiguous or malformed inputs that were previously silently ignored by regex matching will now surface explicit, column-accurate syntax errors.

### ✨ Planned Features & Improvements in 2.0.0

- **New Deterministic Parser & Native Prefix Support**: Fixes long-standing keyword shadowing edge cases (e.g. `date:` and `predef:` vs. alphabetic characters), adds native `:roman` sequence starter support, and delivers pinpoint column-level live validation feedback.
- **Non-Destructive Live Preview**: Opening the sequence input box will no longer pre-delete selected text in the document before confirmation — preventing unnecessary dirty-file indicators and keeping your editor Undo (`Ctrl+Z`) history completely clean when cancelling with `Escape`.
- **Upgraded Input Box with Quick-Action Toolbar**: Direct action buttons inside the main input box to save the current expression as a Preset (`⭐`), switch into the interactive Wizard (`🪄`), or open History (`🕒`).
- **Smart Selection Transformations & Additional Generators**: Simpler relative transformations on already selected document text/numbers, plus expanded DevOps/sequence generators.
