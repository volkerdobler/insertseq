# What's New — Version 1.3.0

## Highlights (1.3.0)

- **Quick Presets / Favorites**: Save, name, preview, and reuse frequently used sequences via `insertseq.presets` and `insertseq.savePreset`.
- **Interactive Wizard / Assistant**: Build sequences step-by-step with `insertseq.wizard` and transfer the generated expression into the normal input flow.
- **Native Ghost-Text Preview**: Improved live preview with better validation/error feedback directly while typing.
- **Internationalization (i18n)**: Validation messages and syntax hints now support localized output.
- **Expression & Preview Improvements**: Typed scope-variable handling in expression evaluation and more responsive (debounced) preview updates.
- **Safer Multi-Cursor Apply Flow**: Document insertion now uses an atomic `vscode.WorkspaceEdit`-based apply step.
- **Testing Modernization**: Unit tests migrated to Vitest with modularized test suites.
- **Date Step Fix**: `%` date sequences now reliably use a 1-day default step when no explicit step is provided.
- **Release Notes Behavior Update**: The extension now shows the newest available release note for the current `MAJOR.MINOR` line only once per shown note version.
- **CI Update**: Added/updated GitHub Actions workflow (master-only branch trigger) and publish now reuses the VSIX artifact from the build job.
